# Review Requests 广告准备

公开资料核对：2026-10-16。以下是规则/产品资料核验，不代表账户已开放或线上执行已验收。

官方于 2026-09-29 宣布 Review Requests 计划在 2026 年 10 月下旬于美国公开测试。截至此次核对，只能标 ANNOUNCED，不能写成本账户已开通。它是广告产品，与后台 Request a Review、Vine 分别核验。

准备时核对账户状态、商品资格、实际开放日期与当前门槛；公告的少于 1000 评分/评论及到阈值暂停要求，须以实时页面复核。核算广告预算、合规评价邀请成本和整体贡献，不将所有新增评论归因于广告；有对照才估计增量。

仅可向符合平台条件的真实购买者展示中立邀请，不筛选满意顾客、不要求星级、不返现换评价。没有真实开放与执行授权时仅给资格检查和试验卡。
