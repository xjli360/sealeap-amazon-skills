# 实体与虚拟捆绑合规

公开资料核对：2026-10-16。以下是规则/产品资料核验，不代表账户已开放或线上执行已验收。

美国公告规定 2027-01-11 起，多数单 ASIN 实体捆绑需原始制造商/品牌方包装。授权重包装、礼品浏览节点/相机产品类型及 Virtual Bundles 有相应例外，逐条核验，不能归纳成「所有捆绑禁止」或「白牌配件都豁免」。

在方案前建立组件品牌、包装主体、销售配置、授权书、类目、是否物理合包和平台资格矩阵。授权必须覆盖具体重包装及组合，不能用一般经销授权替代。虚拟捆绑是独立路径，不把实体包改名即当虚拟捆绑。

记录现有库存、补货交期、截止前可售预测与未售余量，计算改包装/授权/退出成本；没有证据时不新增未验证补货承诺。存量风险不等于授权自动下架或销毁。
