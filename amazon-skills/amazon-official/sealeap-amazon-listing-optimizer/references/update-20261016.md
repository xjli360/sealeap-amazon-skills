# 模块化标题、A+ 与问题分层

公开资料核对：2026-10-16。以下是规则/产品资料核验，不代表账户已开放或线上执行已验收。

## 标题与静态校验

规则未知不能回退为单标题 200 字符。先从真实 PTD/政策确定 modular 或 single，记录来源、时间、适用范围，再运行脚本。Item Highlights 纳入声明、风险词、关键词覆盖与前台冗余检查。

## A+ API 执行准备

2026-09-30 官方更新扩展 Premium A+、Brand Story 模块及媒体操作。先核验品牌/账户资格与当前 API 模型，再建立模块与素材 ID、文本、alt text、适用 ASIN、语言和审核状态的清单。读取已有文档与关联，避免意外替换其他 ASIN 内容。素材创建、内容验证、提交审核、关联 ASIN 与前台生效逐级回读；不把媒体上传成功等同 A+ 已发布。权限不支持时仍可交付草稿与人工操作清单。

## Listing issues 分层

读取问题响应的 PRODUCT / LISTING 分类，区分 ASIN 目录级与 seller-SKU 级问题；缺分类写 UNKNOWN。不能通过改本 SKU 的价格/库存修复所有商品目录问题。

- [模块化标题](https://developer-docs.amazon/sp-api/docs/submit-modular-titles)
- [2026-09-30 API 更新](https://developer-docs.amazon/sp-api/docs/sp-api-release-notes)

## 危险品条件分支

官方公告标注 2026-10-26 起，部分制冷设备、减震/支撑部件、书写工具及泳池/水疗化学品在创建或编辑时增加危险品问题；同一公告仍残留 8/31 日期，故生效细节为 NEEDS_RECONFIRMATION，不能自动写入确定截止日。

上架前按目标 product type 拉当前 PTD/后台必填项，准备制冷气体、减震机制、墨水、化学成分和包装的真实资料；不为通过验证填写假「无危险品」。保存字段、枚举、来源、验证时间和材料证据。缺 SDS/豁免资料或不能确定分类时 HOLD；不自行撤销现有合规属性。

[官方新增问答公告](https://sellercentral.amazon.com/seller-forums/discussions/t/1dd5ad3d-52e6-4e75-ad05-8ae21cdc84f6)

## API 过渡兼容与目录回读

官方 API 指南同时保留过渡行为：不提交 Item Highlights 时，76–200 字符的 item_name 仍可被接收，Amazon 可能自动拆成目录中的标题与亮点。不能把它写成必然 API 拒绝。getListingsItem/searchListingsItems 返回原提交值，不足以证明目录和前台未被拆分。

新模块化草稿使用 `title_structure=modular`；只有取得目标范围的当前兼容证据时，才可使用 `api_legacy`（无亮点、最多200）并保留警告。媒体/其他单字段例外使用 `single` 和明确限制。三种模式都要记录规则来源/核验日期；不要把兼容接收当作推荐展示或平台合规认证。
