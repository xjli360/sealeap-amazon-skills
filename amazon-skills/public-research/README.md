## 使用与验证边界

复制单个完整目录即可使用；每个包包含 SKILL.md、agents/openai.yaml、references、LICENSE 与 NOTICE。三个计算脚本仅使用 Python 标准库、不联网、不提交账户变更；示例数据均为 SYNTHETIC。支持 Python 3.10 或更新版本。输出写任务目录，不覆盖安装包。

公开官方来源、日期与适用范围保存在各包的参考文件中；社媒原帖、原始视频、逐字转写、账号与私人来源映射不随包发布。视频候选未取得完整转写的部分，以完整官方资料独立补充，不声称复现其演示。
