# 第一方数据准备与试验

数据表记录来源系统、用途、授权依据、收集期、字段、保留期、删除责任、目标账户和所需最小数据量。不给公开报告附客户明细；质量报告用聚合值和匿名示例。

事件需区分 event_time 与 upload_time，确认同一转化不会由多个通道重复上传。保留原始 event_id、时区、币种及归因窗口；回传金额是否含税运费依当前定义记录。

质量核查按原始有效行、提交行、接收行、拒绝行、可匹配行、最终受众人数分开；各阶段分母可能不同，不能统一叫匹配率。重复、格式无效、过期与权限问题分别归类。

实验记录目标、受众/排除、随机化单位或可比对照、预算上限、主要指标、成熟窗口、停止线和干扰因素。不能只用再营销 ROAS 高就断言新增需求；同时观察自然替代、总销售、退货与贡献。
